## 下一项最高价值工作

桌面主线下一阶段是为AF_UNIX增加用户态 `bind/listen/accept`、通用ancillary data/credentials，并把当前受信单session扩成多client object ownership；持续PS/2→Wayland input、XKB v1 keymap、动态焦点、Linux poll与统一socket/config event loop已经完成。现有单页memfd mapping也需扩成通用mmap/munmap与多页生命周期，之后才能迁入真正用户态compositor、独立Waybar layer-shell client与swww服务；通用进程主线仍需任意路径/多 `PT_LOAD` exec、通用wait/signal、独立thread/kernel stack与SMP run queue。
